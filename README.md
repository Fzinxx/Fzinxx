Projeto desenvolvido em equipe como trabalho de conclusão de curso de Sistemas para Internet na UniALFA.

O sistema reúne um site para clientes e um painel administrativo para apoiar as atividades da Estância.

**Minha contribuição:**

- Elaboração de diagramas do sistema.
